# Security policy

reusable-ci is published by the `diggsweden` GitHub org and follows
the disclosure process defined in the org-level security policy at
[`diggsweden/.github` → SECURITY.md](https://github.com/diggsweden/.github/blob/main/SECURITY.md).

**Report a vulnerability**: email **ospo AT digg.se** with the
project URL, whether the issue is already public, and a precise
description. The OSPO will respond within a few weeks with an accept
or reject decision; please keep the issue confidential until a
coordinated public announcement.

For what's in scope, see [`docs/threat-model.md`](docs/threat-model.md).

## Forking this repository

If you fork reusable-ci into a different org, replace this file with
your own disclosure contact and process before publishing. The relative
link in `docs/threat-model.md` resolves to whatever sits here, so
keeping a local `SECURITY.md` keeps the threat model self-contained.
